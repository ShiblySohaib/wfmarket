# WFmarket
- uses warframe api v2
- lets user entry own inventory items
- searches and shows top posted offers from the buyers for those items in the market
- boolean search is implemented for all pages for advanced lookup
- user can set how much balance he has for each shop and filter affordable items in the market
- user can copy the whisper to the buyer and use it in game
- the auto refresh interval and colors are customizable
- concurret request limit is customizable
